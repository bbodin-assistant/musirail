# Security policy

Please do not open a public issue for a vulnerability that could expose user
files, bypass package validation, or compromise release signing.

Use GitHub's **Report a vulnerability** private security advisory form for
`bbodin/musirail`. Include reproduction steps, affected versions, and any
suggested mitigation. You should receive an initial response within seven
days.

Only the latest tagged release and the current `main` branch receive security
fixes while the project is in early development.
