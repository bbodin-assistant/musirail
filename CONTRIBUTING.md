# Contributing

Thank you for improving Musirail.

1. Discuss substantial features in an issue before implementing them.
2. Fork the repository and create a focused branch from `main`.
3. Do not commit copyrighted songs, covers, credentials, generated build
   directories, or Android signing material.
4. Run `make check-public`, the Python tests, and the Godot song-library test.
5. Keep UI text and documentation in English.
6. Open a pull request describing the behavior change and how it was tested.

By contributing, you agree that your contribution is licensed under the MIT
license. Assets must be original or have a clearly documented compatible
license in `ASSET_LICENSES.md`.
