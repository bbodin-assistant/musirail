# First Light demo song

`First Light` is an original, deterministic demo composition created for
Musirail. Run `make demo-song` to rebuild its `.musirail` seed package.

The audio, chart, metadata, and generated cover artwork are dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
by bbodin. The cover was produced with OpenAI's built-in image generation tool
from an original prompt and contains no third-party source image.

The generated seed package is copied into the app-managed song library only
when that library is first created. Deleting the demo from the app does not
restore it on later launches.
